AI 사용 시

Ollama for Windows를 설치한 뒤 PowerShell에서 아래 명령어로 모델을 다운로드하세요. 처음에는 모델 다운로드에 시간이 필요해요.

ollama pull exaone3.5:2.4b

Groomi의 설정 → AI 모델 설정에서 Ollama 실행 상태를 확인하고, 다운로드한 모델을 선택하세요.

다른 모델을 사용하고 싶어요

위 명령어는 작은 모델로 시작하는 예시예요. PC 성능에 맞는 다른 로컬 모델도 선택할 수 있습니다. EXAONE 모델 목록에서 크기와 모델 정보를 확인하세요. 모델에 따라 한국어 표현과 생성 품질이 달라집니다.

03
YOUR FIRST CHAPTER

작품과 첫 회차를 만드세요

  1. 작업 폴더를 선택하고 워크스페이스를 만드세요.
  2. 작품 그룹을 추가하고 장편 / 단편을 선택하세요.
  3. 그룹 안에 회차를 추가한 뒤 초안이나 원고를 작성하세요.
  4. 저장 상태를 확인하고, 필요할 때 저장 버튼으로 저장하세요.
장편은 이전 회차의 맥락을 이어갑니다. 단편은 회차마다 독립된 이야기로 다룹니다.

AI 댓글은 가상 반응이에요. 설정과 문장에 대한 판단은 원고와 함께 직접 확인해주세요.
궁금한 점이 있나요?

시작 전에 알아두면 좋아요.

원고가 외부 AI 서비스로 전송되나요?

Groomi의 AI 생성은 내 컴퓨터에서 실행 중인 Ollama를 사용합니다. 로컬 모델을 준비한 뒤 원고를 분석하며 외부 클라우드 LLM을 사용하지 않습니다. 앱과 모델을 처음 다운로드할 때는 인터넷 연결이 필요해요.

AI 생성에 시간이 오래 걸려요.

모델 크기, 원고 길이, 댓글 개수와 PC 성능에 따라 시간이 달라져요. 작은 모델과 적은 댓글 개수로 먼저 확인해보세요. 생성 중 PowerShell에서 ollama ps를 실행하면 PROCESSOR 열에서 CPU / GPU 사용을 확인할 수 있습니다. GPU 지원은 하드웨어와 드라이버에 따라 달라요. Ollama Windows 안내

모델 목록이 보이지 않아요.

Ollama가 실행 중인지 확인하고, PowerShell에서 ollama list로 다운로드한 모델을 확인하세요. 설치 직후 명령어가 인식되지 않으면 새 PowerShell 창을 열어보세요. 이후 Groomi 설정에서 실행 상태와 모델 목록을 다시 확인해주세요.

인물과 해결된 떡밥도 다시 볼 수 있나요?

네. 인물과 떡밥은 그룹 단위로 이어서 관리됩니다. 마지막 회차에 새 정보가 없어도 그룹 상세에서 확인할 수 있어요. 해결된 떡밥도 조회·수정할 수 있지만 댓글 생성은 해당 회차 시점에 미해결인 떡밥만 참고합니다. 이후 회차에서 생긴 정보는 이전 회차의 댓글에 들어가지 않아요.

원고는 어디에 저장되나요? 백업은 어떻게 하나요?

선택한 작업 폴더에 원고 파일과 로컬 데이터베이스가 저장됩니다. 설정의 작업 폴더 백업 기능으로 백업하고, 저장 문제가 생기면 회차의 이전 저장본 복구 기능을 확인하세요. 백업은 작업 폴더와 별도 위치에 보관하는 것이 좋아요.
