# Groomi v1.4.0

## 변경 사항

- 등장인물과 떡밥을 그룹 단위로 관리하고, 회차별 정보·행동 및 생성·해결 이력을 보존합니다.
- 과거 회차의 댓글에는 해당 회차까지 알려진 인물 정보와 당시 미해결 떡밥만 반영합니다.
- 마지막 회차 정보가 없어도 그룹 상세에서 기존 인물과 떡밥을 확인할 수 있습니다.
- AI가 인물·떡밥의 새 항목과 변경 사항만 출력하도록 개선했습니다. HTML 서식과 동일한 초안·원고의 중복 입력을 제거하고 생성 성능 로그를 추가했습니다.
- 최초 정보 생성 시 AI가 임의 ID를 반환하면 발생하던 오류를 수정했습니다.
- 댓글 선택·전체 삭제와 전체 선택을 추가하고 댓글 카드 높이를 줄였습니다.
- 백그라운드 작업의 실패 사유를 작업 내역에 표시합니다. 해당 회차 생성 중에는 정보 보기 버튼을 비활성화합니다.
- 그룹 정보 안내 깜빡임과 모달 배경 위에 테이블 헤더가 표시되는 문제를 수정했습니다.
- 새 기본 작업 폴더와 DB 이름을 `groomi`, `groomi.sqlite`로 통일했습니다. 기존 DB는 원본을 유지하며 새 이름으로 이전하고 기존 작업 폴더·백업을 지원합니다.

## 설치 및 데이터

Windows x64 설치 파일은 `groomi-1.4.0.exe`입니다.

업데이트 전에 설정에서 작업 폴더 백업을 권장합니다. 이번 버전은 작업 폴더 DB를 형식 4로 업그레이드하므로, 업그레이드한 작업 폴더는 이전 앱 버전에서 열 수 없습니다. 기존 작업 폴더 위치와 원고 파일은 유지합니다.

## 검증

- 타입 검사 및 원고 보호·그룹 이력·DB 이전·일괄 삭제 테스트 27개 통과
- Electron UI와 패키징 앱의 저장·이동·삭제·오류 표시 회귀 테스트

실제 Ollama 생성 속도는 모델과 CPU/GPU 환경에 따라 달라집니다.
