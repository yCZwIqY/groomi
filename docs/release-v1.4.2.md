# Groomi v1.4.2

## 변경 사항

- 백업 성공 날짜를 작업 폴더별로 기록하고, 백업 기록이 없거나 마지막 백업 후 7일 이상 지난 경우 작업실 대시보드에서 안내합니다.
- 설정에서 마지막 백업일을 확인할 수 있습니다. 백업 실패·취소 시 기록을 갱신하지 않습니다.
- Windows 작업표시줄 아이콘에 새 Groomi 아이콘을 명시합니다.
- AI가 요청보다 많은 댓글을 반환하면 요청 개수만 저장하도록 수정했습니다. 부족한 결과는 오류로 안내합니다.
- 소개 페이지의 집필·떡밥 관리·독자 댓글 영역에 실제 앱 캡처를 적용했습니다.

## 설치

Windows x64 설치 파일: `groomi-1.4.2.exe`.
업데이트 전에 설정에서 작업 폴더를 백업해주세요. 기존 원고와 작업 폴더는 유지됩니다.

## 검증

- TypeScript 검사 통과
- 릴리즈 안전성 테스트 29개 통과
- 실제 Electron UI 및 패키징 앱 회귀 검사 통과

AI 생성 속도는 모델과 PC의 CPU/GPU 환경에 따라 달라집니다.
