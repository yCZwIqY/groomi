# Groomi v1.5.0

## 변경 사항

- AI 모델 설정에서 Ollama 로컬 모델 또는 OpenRouter 온라인 모델을 선택할 수 있습니다. OpenRouter API 키는 이 기기에 암호화해 저장하고 작업 폴더 백업에서 제외합니다.
- OpenRouter 키 사용 금액·남은 한도·무료 모델 요청 횟수와 이 기기의 Groomi 입력·출력 토큰 및 생성 요청 수를 표시합니다. 키 한도는 계정 전체 잔액과 다르며, Groomi 집계는 기록 기능 적용 이후부터 누적됩니다.
- 회차 정보는 원고 본문만 분석합니다. 초안만 있거나 원고가 비어 있으면 생성 요청 전에 안내합니다.
- 같은 회차를 다시 생성할 때 이전 생성 결과가 입력에 섞이지 않도록 수정했습니다. 해당 회차의 기존 결과는 새 결과로 대체합니다.
- 장편의 사건은 회차별로 기록하고 누적 줄거리는 분량을 제한합니다. 인물 상태와 떡밥 진행을 관리하고 원고·앞 회차 변경 시 재생성이 필요한 정보를 표시합니다.
- AI 응답의 형식과 인물·떡밥 ID를 검증하고 회차 정보 응답 검증 실패 시 한 번 재요청합니다.
- 댓글 예시와 프롬프트를 조정해 짧은 감탄·질문·혼잣말 등 실제 독자의 즉각적인 반응을 더 다양하게 생성하도록 개선했습니다.
- 온보딩 페이지에 OpenRouter 설정, 사용량 확인, 회차 정보 생성과 재생성 안내를 추가했습니다.
- 사용하지 않는 코드와 파일을 정리했습니다.

## 설치

Windows x64 설치 파일: `groomi-1.5.0.exe`.

업데이트 전에 설정에서 작업 폴더를 백업해주세요. 기존 원고와 작업 폴더는 유지됩니다.

Ollama는 로컬 모델을 사용합니다. OpenRouter를 선택하면 생성할 원고와 관련 회차 정보가 외부 서비스로 전송되며 유료 모델 요금은 본인 OpenRouter 계정에 부과됩니다.

## 검증

- TypeScript 검사 통과
- 릴리즈 안전성 테스트 45개 통과
- Electron UI 및 패키징 앱 회귀 검사 통과

AI 호출은 테스트에서 모의 응답으로 검증했습니다. 실제 생성 품질과 속도는 모델, 제공자와 PC 환경에 따라 달라집니다.
