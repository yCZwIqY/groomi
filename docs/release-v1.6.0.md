# Groomi v1.6.0

원고 작성에 집중할 수 있도록 에디터 화면과 작성 도구를 개선했습니다.

## 주요 변경

- 원고만 보기를 기본으로 열고, 초안과 원고를 분할 화면에서 비교할 수 있습니다.
- 본문에 종이 형태의 여백을 적용하고 글자 수를 하단에 표시합니다.
- 본문 글자 크기와 줄 간격을 조절할 수 있습니다.
- 집중 모드에서 작성 화면을 넓게 사용하고 Esc로 돌아갈 수 있습니다.
- 서식 도구를 선 아이콘으로 정리하고 선택 상태와 실행 취소 가능 여부를 표시합니다.
- 문장부호와 장면 전환용 특수기호를 커서 위치에 삽입할 수 있습니다.
- 기호 팝업이 에디터 영역에 잘리지 않으며, 작은 창과 집중 모드에서도 화면 안에 표시됩니다.
- 저장된 원고를 불러오는 동작을 실행 취소 기록에서 제외합니다.

## 설치

Windows 설치파일 `groomi-1.6.0.exe`를 실행해주세요. 함께 제공하는
`groomi-1.6.0.sha256` 파일로 설치파일의 SHA-256 체크섬을 확인할 수 있습니다.

- 릴리즈 안전성 테스트 45개 통과
